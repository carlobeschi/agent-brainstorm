# sales-chart

Monthly sales per region for 2026, in `data/sales.csv` (month, region, sales in euros).

## The request

> We need one chart for the annual report: how each region's sales moved over
> the year. The report is printed in black and white, so colour alone must not
> be what tells the regions apart. Save it as `chart.svg` in this folder: a
> single file, no fonts or images from the internet, readable at A4 width.
> If something in the data deserves a note, the chart should show it.
